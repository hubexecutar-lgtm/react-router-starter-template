# HOME-BRAIN-001 · correção mobile v1.0.1

Base: hubexecutar-lgtm/react-router-starter-template, main em 4c17b6791ef49f8a56f3e0d60a8eee876a5d4c0a.

Problema: a câmera encaixava o modelo pela altura em telas estreitas, cortando as laterais. Os marcadores se expandiam a partir de posições percentuais e invadiam as bordas e a figura. As partículas tinham tamanho excessivo.

Mudanças: cálculo de distância da câmera pelo campo de visão horizontal; ponto menor e translúcido; palco mobile quadrado; quatro controles compactos nas laterais, em alturas alternadas; teste de regressão para viewport de 320 e 390 px.

Aplique na raiz do monorepo (main no commit base):

    git apply --check apply.patch
    git apply apply.patch
    npm ci
    npm run typecheck -w apps/blog
    npm run build -w apps/blog
    npm run test:brain -w apps/blog

Os arquivos completos também estão em source/ para revisão. TypeScript e build passaram nesta entrega. O teste Playwright não pôde ser executado neste ambiente porque o download do navegador retornou um arquivo inválido; rode-o antes da publicação. Nenhum push ou deploy foi feito.
